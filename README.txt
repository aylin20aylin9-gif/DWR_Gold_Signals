DWR Gold Signals — Gold API edition

تم استبدال Twelve Data بالكامل بمصدر Gold API للسعر اللحظي XAU/USD.

المصدر:
https://gold-api.com/docs

مهم:
- السعر اللحظي لا يحتاج API Key وفق توثيق Gold API.
- الخطة المجانية تعلن عن طلبات غير محدودة لنقطة السعر اللحظي.
- تم إلغاء مفتاح Twelve Data من الكود.
- لا يوجد طلب API منفصل كل دقيقة لجلب 100 شمعة؛ التطبيق يبني شموع 5 دقائق محلياً من السعر اللحظي.
- يتم حفظ الشموع محلياً حتى لا تضيع عند إغلاق التطبيق.
- يحتاج التطبيق إلى تشغيل المراقبة وجمع بيانات كافية؛ عند التثبيت الجديد يحتاج تقريباً 30 دقيقة لجمع 6 شموع مكتملة قبل تحليل CISD.
- هذا التعديل لا يضمن دقة تنفيذ أو ربح التداول؛ الإشارات للاستخدام المعلوماتي فقط.

البناء:
./gradlew assembleDebug
